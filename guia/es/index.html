Qué es

Un proyecto de referencia, separado del curso

Todo lo que sirve de base para el curso "Fable 5.1 na prática", organizado para consulta directa: fuentes con su ponderación, análisis de lo que cambió y fichas listas para copiar. Todo enmarcado por: oficial × extraído e modelo × producto que lo rodea.

🏛️ Dos fuentes, dos pesos

El prompt central que Anthropic publica y firma, y el dump del runtime de Claude.ai (memoria, búsqueda, artefactos, 46 herramientas) que Anthropic no autenticó. El README indica cuál es cuál.

🗺️ Índice del dump

Mapa de las 40 secciones del archivo generado por script, con líneas, tamaño y grupo. Solo metadatos: sabes dónde está cada cosa sin redistribuir el contenido.

📋 Fichas prácticas

Ficha de las 5 pruebas del comprador, reglas para escribirle a Fable (quitar el andamiaje, indicar cuándo) y tabla de costo y esfuerzo. Markdown puro, para copiar.

Cómo funciona

De la fuente original a la ficha que usas

El material fuente queda en local (es de terceros o una extracción no autenticada). Lo que se publica es lo derivado: índice, análisis y fichas.

doc/ (dump + Field Guide)→ build/indice.py→ INDICE-DO-DUMP.md→ ANALISE.md→ fichas/01 · 02 · 03
1

Prompt central (oficial)

Identidad, tono, negativas, bienestar, fecha de corte. Las líneas 2–188 del dump coinciden con lo que publica Anthropic.

2

Capa de producto (solo en el dump)

Memoria (836 líneas, 38% del archivo), conversaciones pasadas, elementos visuales, plugins y skills, búsqueda, artefactos. Aquí creció 2,3x el 5.1.

3

Derivados (publicados)

Índice, análisis y fichas. Con fecha. El producto cambia; el método para volver a auditar cada generación permanece.

Guía de uso · paso a paso

Cinco usos, del más rápido al más profundo

Elige según lo que quieras hacer hoy. Cada paso apunta a un archivo del repositorio.

1

Entiende qué cambió en 5 minutos

Abre el análisis: los tres números (2,3x · +28 herramientas · 75% memoria+schemas), las 28 adiciones en 6 grupos, las nuevas reglas de comportamiento y la paradoja modelo × producto.

cat ANALISE.md  # o léelo en GitHub
2

Encuentra dónde está una regla en el prompt

El índice enumera las 40 secciones con líneas y tamaño, las herramientas encontradas por schema y las 11 skills, además de un orden de lectura sugerido (tono → memoria → conversaciones → elementos visuales → búsqueda → herramientas).

cat INDICE-DO-DUMP.md
# con el dump local, regenerar:
python3 build/indice.py  # 40 secciones · 31 herramientas por "name" · 11 skills
3

Prueba en tu cuenta si aparecen las novedades

Copia la ficha, completa la superficie, el plan y la fecha, y realiza las 5 pruebas: continuidad (memoria), registro (conversaciones pasadas), interfaz (elementos visuales), capacidad (skills/plugins) y control (borrar memoria). Un resultado sin ficha es una impresión; con ficha, es un dato.

cat fichas/01-ficha-dos-5-testes.md
# ejemplo de prompt de la Prueba 2 (registro):
Sobre aquela decisão que tomamos sobre [tema]: qual foi a opção que escolhemos e por quê?
4

Reescribe tus prompts para la nueva generación

Quita el andamiaje ("sé conciso", "piensa paso a paso" ya están en el prompt del sistema), di cuando usa cada capacidad, muestra el formato en vez de prohibir y usa el esqueleto de sep/2026 (resultado, fuente de verdad, autoridad, listo, verificación).

cat fichas/02-escrever-para-o-fable.md
# regla práctica: cada línea del prompt debe contener información que el modelo no tiene
5

Decide el modelo y el esfuerzo según el costo por tarea

Por token, Fable cuesta 2x Opus 5 y 5x Sonnet 5. El ahorro solo existe si se mide por tarea completada: explora el esfuerzo antes de bajar de modelo, ejecuta la opción económica y repite solo lo que falló (si hay un verificador), compara en el 10% más difícil de tu trabajo.

cat fichas/03-custo-e-esforco.md
# orden de las palancas en la API: caché → esfuerzo → presupuesto → modelo, una por vez, midiendo
Las cifras

Fable 5 → Fable 5.1, con el mismo método de conteo

Medidos por el Field Guide a partir de dos dumps no autenticados, congelados el 02/09/2026. Los benchmarks son los que Anthropic decidió publicar.

2,3x

palabras en el prompt capturado: 17.501 → 40.046

+28

herramientas agregadas (46 en total, ninguna eliminada)

75%

del crecimiento corresponde a la memoria (+8.639 palabras) y los schemas (+8.328)

38%

del dump actual es solo la sección memory_filesystem (836 de 2.196 líneas)

🧠 Memoria (6)

list / read / write / append / str_replace / delete. Nunca guarda datos de salud, religión, orientación o pagos. Solo aparece en la respuesta si cambia la sustancia.

🗂️ Conversaciones anteriores (3)

conversation_search, recent_chats, read_conversation. Reabre la conversación original con pistas como "aquella decisión".

📊 Visuales (13) · 🔌 Plugins y skills (4) · 🔎 Investigación (1) · ⏹ Control (1)

La respuesta se convierte en interfaz; sugerencia de capacidad faltante (1 tarjeta por conversación); investigación profunda bajo decisión; detenerse solo por seguridad.
