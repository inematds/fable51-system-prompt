O que é

Um projeto de referência, separado do curso

Tudo que embasa o curso "Fable 5.1 na prática", organizado para consulta direta: fontes com seus pesos, análise do que mudou e fichas prontas para copiar. Moldura em tudo: oficial × extraído e modelo × produto ao redor.

🏛️ Duas fontes, dois pesos

O prompt central que a Anthropic publica e assina, e o dump do runtime do Claude.ai (memória, busca, artefatos, 46 ferramentas) que a Anthropic não autenticou. O README diz qual é qual.

🗺️ Índice do dump

Mapa gerado por script das 40 seções do arquivo, com linhas, tamanho e grupo. Só metadados: você sabe onde está cada coisa sem redistribuir o conteúdo.

📋 Fichas práticas

Ficha dos 5 testes do comprador, regras para escrever para o Fable (tirar o andaime, dizer o quando) e tabela de custo e esforço. Markdown puro, para copiar.

Como funciona

Da fonte bruta à ficha que você usa

O material-fonte fica local (é de terceiros ou extração não autenticada). O que se publica é o derivado: índice, análise e fichas.

doc/ (dump + Field Guide)→ build/indice.py→ INDICE-DO-DUMP.md→ ANALISE.md→ fichas/01 · 02 · 03
1

Prompt central (oficial)

Identidade, tom, recusas, bem-estar, data de corte. Linhas 2–188 do dump batem com o que a Anthropic publica.

2

Camada de produto (só no dump)

Memória (836 linhas, 38% do arquivo), conversas passadas, visuais, plugins e skills, busca, artefatos. É aqui que o 5.1 cresceu 2,3x.

3

Derivados (publicados)

Índice, análise e fichas. Datados. O produto muda; o método de reauditar a cada geração fica.

Guia de uso · passo a passo

Cinco usos, do mais rápido ao mais profundo

Escolha pelo que você quer fazer hoje. Cada passo aponta para um arquivo do repositório.

1

Entenda o que mudou em 5 minutos

Abra a análise: os três números (2,3x · +28 ferramentas · 75% memória+schemas), as 28 adições em 6 grupos, as regras de comportamento novas e o paradoxo modelo × produto.

cat ANALISE.md  # ou leia no GitHub
2

Ache onde uma regra mora no prompt

O índice lista as 40 seções com linhas e tamanho, as ferramentas achadas por schema e as 11 skills, mais uma ordem de leitura sugerida (tom → memória → conversas → visuais → busca → ferramentas).

cat INDICE-DO-DUMP.md
# com o dump local, regenerar:
python3 build/indice.py  # 40 seções · 31 ferramentas por "name" · 11 skills
3

Teste na sua conta se as novidades aparecem

Copie a ficha, preencha superfície, plano e data, e rode os 5 testes: continuidade (memória), registro (conversas passadas), interface (visuais), capacidade (skills/plugins) e controle (apagar memória). Resultado sem ficha é impressão; com ficha é dado.

cat fichas/01-ficha-dos-5-testes.md
# exemplo de prompt do Teste 2 (registro):
Sobre aquela decisão que tomamos sobre [tema]: qual foi a opção que escolhemos e por quê?
4

Reescreva seus prompts para a nova geração

Tire o andaime ("seja conciso", "pense passo a passo" já estão no prompt de sistema), diga quando usar cada capacidade, mostre o formato em vez de proibir, e use o esqueleto de set/2026 (resultado, fonte de verdade, autoridade, pronto, verificação).

cat fichas/02-escrever-para-o-fable.md
# regra de bolso: cada linha do prompt deve conter informação que o modelo não tem
5

Decida modelo e esforço pelo custo por tarefa

Por token o Fable custa 2x o Opus 5 e 5x o Sonnet 5. A economia só existe medida por tarefa concluída: varra o esforço antes de descer de modelo, rode barato e refaça só o que falhou (se houver checador), compare na décima parte mais difícil do seu trabalho.

cat fichas/03-custo-e-esforco.md
# ordem das alavancas na API: cache → esforço → orçamento → modelo, uma por vez, medindo
Os números

Fable 5 → Fable 5.1, no mesmo método de contagem

Medidos pelo Field Guide sobre dois dumps não autenticados, congelados em 02/09/2026. Benchmarks são os que a Anthropic escolheu publicar.

2,3x

palavras no prompt capturado: 17.501 → 40.046

+28

ferramentas adicionadas (46 no total, nenhuma removida)

75%

do crescimento é memória (+8.639 palavras) e schemas (+8.328)

38%

do dump atual é só a seção memory_filesystem (836 de 2.196 linhas)

🧠 Memória (6)

list / read / write / append / str_replace / delete. Nunca guarda saúde, religião, orientação, pagamento. Só entra na resposta se mudar a substância.

🗂️ Conversas passadas (3)

conversation_search, recent_chats, read_conversation. Reabre a conversa original por pistas como "aquela decisão".

📊 Visuais (13) · 🔌 Plugins e skills (4) · 🔎 Pesquisa (1) · ⏹ Controle (1)

Resposta vira interface; sugestão de capacidade faltante (1 cartão por conversa); pesquisa profunda sob decisão; parada só para segurança.
