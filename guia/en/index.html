What it is

A reference project, separate from the course

Everything that supports the course "Fable 5.1 in Practice," organized for quick reference: sources and their weights, an analysis of what changed, and ready-to-copy reference cards. The framing throughout: official × extracted e model × surrounding product.

🏛️ Two sources, two weights

The central prompt Anthropic publishes and signs, and the Claude.ai runtime dump (memory, search, artifacts, 46 tools), which Anthropic has not authenticated. The README identifies which is which.

🗺️ Dump index

Script-generated map of the file’s 40 sections, with line counts, size, and group. Metadata only: you can see where everything is without redistributing the content.

📋 Practical reference sheets

Form for the buyer's 5 tests, rules for writing for Fable (remove the scaffolding, say when), and a cost and effort table. Plain Markdown, ready to copy.

How it works

From raw source to a form you can use

The source material stays local (it’s from a third party or an unauthenticated extraction). What gets published is the derivative work: index, analysis, and reference cards.

doc/ (dump + Field Guide)→ build/indice.py→ INDICE-DO-DUMP.md→ ANALISE.md→ reference-cards/01 · 02 · 03
1

Central prompt (official)

Identity, tone, refusals, well-being, cutoff date. Lines 2–188 of the dump match what Anthropic publishes.

2

Product layer (dump only)

Memory (836 lines, 38% of the file), past conversations, visuals, plugins and skills, search, artifacts. This is where 5.1 grew 2.3x.

3

Derivatives (published)

Index, analysis, and reference sheets. Dated. The product changes; the method of reauditing each generation remains.

Prerequisites

Almost nothing: just reading and copying

You only need a browser to read the reference cards. To regenerate the index, you need Python 3 and the local dump.

Clone the repository

The derived files come with the clone. The folder doc/ doesn't come with it.

# clone
git clone git@github.com:inematds/fable51-system-prompt.git
cd fable51-system-prompt

Local dump (optional)

Only needed to regenerate the index. The original file is public in the CL4R1T4S repository, in the ANTHROPIC folder.

# save as doc/Claude-Fable-5.1.md
mkdir -p doc
# expected md5: be4cb3a5103be5c1c581afac2a04b1d0

Python 3

No external dependencies.

python3 --version
User Guide · step by step

Five ways to use it, from quickest to deepest

Choose based on what you want to do today. Each step points to a repository file.

1

Understand what changed in 5 minutes

Open the analysis: the three numbers (2.3x · +28 tools · 75% memory+schemas), the 28 additions in 6 groups, the new behavior rules, and the model × product paradox.

cat ANALISE.md  # or read it on GitHub
2

Find where a rule lives in the prompt

The index lists the 40 sections with line counts and size, the tools found by schema, and the 11 skills, plus a suggested reading order (tone → memory → conversations → visuals → search → tools).

cat INDICE-DO-DUMP.md
# with the local dump, regenerate:
python3 build/indice.py  # 40 sections · 31 tools by "name" · 11 skills
3

Check your account to see if the new features appear

Copy the form, fill in the surface, plan, and date, then run the 5 tests: continuity (memory), records (past conversations), interface (visuals), capability (skills/plugins), and control (delete memory). A result without a form is an impression; with a form, it's data.

cat fichas/01-ficha-dos-5-testes.md
# Test 2 prompt example (record):
Sobre aquela decisão que tomamos sobre [tema]: qual foi a opção que escolhemos e por quê?
4

Rewrite your prompts for the new generation

Remove the scaffolding ("be concise," "think step by step" are already in the system prompt), tell when use each capability, show the format instead of prohibiting it, and use the Sep/2026 skeleton (result, source of truth, authority, ready, verification).

cat fichas/02-escrever-para-o-fable.md
# rule of thumb: every line of the prompt should contain information the model doesn't have
5

Choose a model and effort based on cost per task

Per token, Fable costs 2x as much as Opus 5 and 5x as much as Sonnet 5. You only save money when you measure by completed task: sweep through the effort before dropping to a smaller model, run it cheaply and redo only what failed (if you have a checker), and compare on the most difficult tenth of your work.

cat fichas/03-custo-e-esforco.md
# API tuning order: cache → effort → budget → model, one at a time, measuring

🧠 Memory (6)

list / read / write / append / str_replace / delete. Never stores health, religion, orientation, or payment information. Only included in a response if it changes the substance.

🗂️ Past conversations (3)

conversation_search, recent_chats, read_conversation. Reopens the original conversation using clues like "that decision."

📊 Visuals (13) · 🔌 Plugins and skills (4) · 🔎 Research (1) · ⏹ Control (1)

Responses become interfaces; suggestion for a missing capability (1 card per conversation); deep research at your discretion; stop only for safety.
